# Motion inventory

Every animation on the page, the token it reads, and where the code lives. Edit `styles/tokens.css` to tune timings, distances and easings; the code reads tokens at init. Progress windows and geometry constants live in the `HERO` object at the top of `components/hero/HeroChoreography.tsx`.

Conventions: **p** is the pinned-scrub timeline progress (0 = pin starts, 1 = pin releases after exactly one viewport of scroll). "Mirrors" means the horizontal component is multiplied by −1 in Arabic (`dirX`); vertical motion is never mirrored.

## Boot signals

Two attributes on `<html>` gate everything above: `data-js` (the hero pre-hide only applies with JavaScript) and `data-fonts` (the page stays `visibility: hidden` until both font families are in, 1 s timeout, so the swap can never register as a layout shift). The inline script in the layout sets them before first paint; `components/motion/BootSignals.tsx` re-applies them in a layout effect after every mount, because React 19 strips all attributes from `<html>` when the locale layout remounts on a soft navigation. The hero choreography waits for `data-fonts` before it measures anything.

## Guard rails

- `prefers-reduced-motion: reduce`: no pin, no scrub, no reveals; the hero mirror is `display: none` and the in-flow grid renders as static content.
- Below 1024px wide or 760px tall: no pin; the mirror is hidden and the hero exits on its own scroll (M1–M5). Below 1024 the tiles are not rendered and the hero lifts the first benefit card (M6); cards 2–3 reveal in flow. The short layout keeps its tile grid (a 24px rise) and reveals all three cards in flow.
- Triggers are killed and rebuilt on locale change and after a debounced resize (`RESIZE_DEBOUNCE_MS`); `ScrollTrigger.refresh()` runs after `document.fonts.ready`.
- Geometry (tile pile, handover square and landing positions) is re-measured on every refresh with transforms cleared, and every start value is applied by a function-valued `set`, so a font swap or resize mid-pin cannot leave the card morphing from or landing on the wrong rectangle.
- The scrub timeline is padded to exactly 1 (`tl.set({}, {}, 1)`): ScrollTrigger maps the pin onto the timeline's duration, so the `P` windows only read as scroll fractions while that holds.
